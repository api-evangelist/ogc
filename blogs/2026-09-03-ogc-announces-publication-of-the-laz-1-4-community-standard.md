The Open Geospatial Consortium (OGC) is excited to announce the publication of the LAZ 1.4 Community Standard, which defines a lossless compression format for LAS 1.4 point cloud data. LAZ uses lossless compression to reduce the size of a LAS file while maintaining the general structure of the LAS format.
